# Сайт АлМакс

Статичный одностраничный сайт без сборки и зависимостей. Чтобы посмотреть, откройте `index.html` в браузере. Форма и каталог работают только через веб-сервер, например `python3 -m http.server 8765` → http://localhost:8765.

## Файлы
- `index.html` — разметка: шапка, hero с огнём, решения (слайдер), условия, каталог, как заказать, заявка, подвал. В `<head>` — мета-теги для поиска и соцсетей и разметка Organization (schema.org)
- `privacy.html` — политика обработки персональных данных (шаблон по Закону РБ № 99-З)
- `styles.css` — все стили, цвета в `:root`, мобильная версия в блоке `@media (max-width: 720px)`, внизу — стили страницы политики
- `script.js` — слайдер, каталог и заявка
  - `FORM_ENDPOINT` — адрес, куда отправлять заявку (пока пусто: форма только показывает «Заявка отправлена»)
  - `TURNSTILE_SITEKEY` — ключ капчи Cloudflare Turnstile (пока пусто: капча не показывается)
  - `PRODUCTS` — список моделей каталога (карточки строятся из него); `w` и `h` — размеры фото в пикселях
- `images/` — обработанные фото в WebP; `og-image.jpg` — картинка 1200×630 для превью ссылки в мессенджерах и соцсетях
- `fonts/` — шрифт Inter (вариативный, кириллица и латиница), подключается локально без Google Fonts
- `favicon.ico`, `favicon.svg`, `apple-touch-icon.png` — иконки сайта
- `robots.txt`, `sitemap.xml` — для поисковиков

На хостинг выкладывается всё, кроме `README.md` и папки `.claude/` (настройки локального превью).

## Заявка
Форма проверяет имя, телефон (белорусские номера `+375…` и `80…`, а также зарубежные: от 9 до 15 цифр) и галочку согласия на обработку персональных данных. Во время отправки кнопка заблокирована, ошибки показываются под формой.

Заявка уходит POST-запросом в JSON:
```json
{
  "name": "Иван",
  "phone": "+375 29 123-45-67",
  "comment": "…",
  "items": [{ "sku": "DY-818", "name": "Пьезо, классическая", "qty": "1000" }],
  "consent": true,
  "website": "",
  "cf-turnstile-response": "<токен капчи>"
}
```

Защита от спама:
- **Ловушка** — скрытое поле `website`. Человек его не видит; если оно заполнено, скрипт не отправляет заявку. Сервер тоже должен отбрасывать заявки с непустым `website`: бот может отправить запрос напрямую, минуя страницу.
- **Капча Cloudflare Turnstile.** Чтобы включить:
  1. В панели Cloudflare: Turnstile → Add widget, домен сайта, режим Managed. Это бесплатно.
  2. Site key вписать в `TURNSTILE_SITEKEY` в `script.js`.
  3. Secret key хранить только на сервере. Обработчик заявки обязан проверять каждый токен запросом `POST https://challenges.cloudflare.com/turnstile/v0/siteverify` с полями `secret`, `response` (= `cf-turnstile-response`) и `remoteip` и принимать заявку только при `"success": true`. Без серверной проверки капча ничего не защищает.

## Что заменить перед запуском
- Телефон `[+375 XX XXX-XX-XX]` — в шапке, в контактах, в `href="tel:..."`, в разметке Organization в `index.html` и в `privacy.html`
- E-mail `[info@almaks.by]` и УНП `[XXXXXXXXX]` — в `index.html` (контакты, подвал, разметка Organization) и в `privacy.html`
- Адрес сайта `https://almaks.by/`, если домен другой, — в `index.html` (canonical, `og:url`, `og:image`, Organization), `privacy.html` (canonical), `robots.txt`, `sitemap.xml`
- В `privacy.html` — значения в `[квадратных скобках]`: дату редакции, срок хранения, хостинг и сервис приёма заявок. Перед публикацией текст должен проверить юрист. Если капча не нужна, уберите из политики пункты про Cloudflare
- Подключить отправку заявки: `FORM_ENDPOINT` в `script.js` (свой скрипт на хостинге, бот Telegram и т. п.) с серверной проверкой капчи и ловушки — см. «Заявка»
- Найти все оставшиеся заглушки можно поиском по `[`: `grep -rn "\[" --include=*.html .`
